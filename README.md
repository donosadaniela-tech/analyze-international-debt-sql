# Analyze International Debt Statistics (SQL)

## 📌 Project Overview
This project analyzes international debt data from the World Bank using SQL. 
The goal is to explore debt distribution across countries and indicators. The dataset contains information about the amount of debt (in USD).

## 🛠️ Tools & Skills
- SQL
- Aggregations (SUM, AVG)
- GROUP BY, ORDER BY

## 📊 Key Questions
- What is the number of distinct countries present in the database?
- What country has the highest amount of debt?
- What country has the lowest amount of repayments?
